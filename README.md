# Guardian Shield

Guardian Shield is a web-based application designed to help users block adult content and create a safer browsing environment. Built using modern web technologies, it runs directly in the browser to filter and manage access safely and efficiently.

## Features

* **Content Filtering:** Assists in blocking unwanted or adult-oriented websites.
* **Lightweight & Fast:** Executes directly in the browser without relying on heavy external infrastructure.
* **Easy Access:** Hosted live via GitHub Pages for instant availability on any device.
